# ТВ Каналы

Приложение для Android TV. Оно показывает российские каналы из открытых
источников. Интерфейс повторяет меню приставки Триколор.

Приложение работает на стике realme 4K Google TV Stick (RMV2105). Другие
устройства на Android TV 7 и новее тоже подходят.

## Возможности

- При запуске приложение сразу включает последний канал. В настройках
  можно выбрать первый канал.
- Каналы 1–20 — федеральные, в привычном порядке.
- У канала бывает несколько ссылок на поток. При ошибке приложение
  переходит на следующую ссылку.
- Приложение выбирает лучшее качество. Качество снижают, только если
  в буфере осталось меньше 6 с.
- Телепрограмма показывает передачи: прошедшие, текущую и следующие.
- Приложение получает новый список каналов с GitHub. Переустанавливать приложение не нужно.

## Пульт

| Кнопка | Действие |
|---|---|
| OK | Открывает меню каналов |
| OK, удерживать в меню | Добавляет канал в «★ Избранное» или убирает из него |
| Вправо, влево | Включает следующий или предыдущий канал |
| Вверх | Открывает телепрограмму канала |
| Вниз | Открывает вкладку «Недавние» |
| Цифры | Включают канал по номеру |
| Назад | Закрывает меню. При просмотре два нажатия закрывают приложение |

Если кнопку «вправо» или «влево» придержать, канал меняется один раз.

В телепрограмме кнопки «вправо» и «влево» переключают канал. Кнопка OK
включает этот канал. Передача под фокусом всегда стоит по центру экрана.

## Меню

Меню содержит вкладки:

- «Недавние» — последние 30 каналов;
- «★ Избранное»;
- «Все каналы»;
- категории: «Федеральные», «Детские», «Кино и сериалы» и другие;
- «⚙ Настройки».

В настройках выбирают:

- канал при запуске: последний или первый;
- предел качества: максимальное, 1080p, 720p или 480p;
- пропуск нерабочих каналов при переключении;
- показ региональных каналов;
- время показа плашки с названием канала;
- таймер сна.

Внизу экрана настроек приложение пишет источник списка каналов: GitHub, APK или adb.

## Установка

1. Установите Android SDK в каталог `~/Android/Sdk`.
2. Соберите приложение:

   ```bash
   ANDROID_HOME=~/Android/Sdk ./gradlew assembleRelease
   ```

3. Включите на стике отладку по сети. Запишите адрес стика в переменную:

   ```bash
   export TV_STICK=192.168.1.50:5555
   ```

4. Подключитесь к стику по ADB (отладочный мост Android):

   ```bash
   adb connect $TV_STICK
   ```

5. Установите приложение:

   ```bash
   adb -s $TV_STICK install -r app/build/outputs/apk/release/app-release.apk
   ```

## Список каналов

Приложение читает список каналов в таком порядке:

1. Файл `channels.m3u` в каталоге приложения. Его кладут через `adb push` для отладки.
2. Список с GitHub. Приложение скачивает его при прошлом запуске.
3. Список из APK (пакет приложения Android).

Список каналов собирают в отдельном репозитории
[tv-channels-list](https://github.com/Briaks01/tv-channels-list). Там же
лежат скрипты сборки, источники потоков и расписание GitHub Actions.

При каждом запуске приложение скачивает свежий список с GitHub. Сначала
приложение запрашивает raw.githubusercontent.com, при ошибке — зеркало
jsDelivr. Новый список применяют со следующего запуска. Так номера
каналов остаются прежними во время просмотра.

Список в APK нужен, только если GitHub не отвечает. Перед релизной сборкой
обновите его скриптом:

```bash
tools/update_bundled_list.sh
```

### Формат файла

Файл `channels.m3u` имеет формат M3U:

- под строкой `#EXTINF` стоят одна или несколько ссылок на поток;
- первая ссылка основная, остальные запасные;
- атрибут `x-hls="1"` указывает поток HLS (потоковая передача по HTTP);
- атрибуты `x-mailru` и `x-epg` указывают канал в телепрограмме;
- атрибут `x-logo` указывает имя файла логотипа.

Ссылки с префиксами `okru:`, `vitrina:` и `vkplay:` содержат не поток,
а адрес плеера. Ссылку на поток приложение получает перед запуском.
Токены этих источников действуют от суток до недели.

## Телепрограмма

Приложение загружает телепрограмму при открытии и хранит её в памяти
6 часов. На диск телепрограмму не скачивают.

Источники телепрограммы:

1. tv.mail.ru — передачи текущих телесуток. Сайт работает в России.
   Стик открывает его без ошибок.
2. epg.iptvx.one — передачи на неделю. Сайт работает через Cloudflare.
   Часть провайдеров его не пропускает. После ошибки приложение 10 минут
   не запрашивает этот сайт.

Каналы с идентификаторами этих сайтов сопоставляет скрипт `tools/epg_ids.py` в репозитории списка.

## Проверка

### Тесты

Тесты проверяют разбор списка каналов и телепрограммы. Сеть им не нужна.

```bash
ANDROID_HOME=~/Android/Sdk ./gradlew testDebugUnitTest
```

### Самопроверка на стике

Отладочная сборка записывает журнал событий с тегом `ST`. Скрипт
`tools/selftest.py` нажимает кнопки пульта через ADB и разбирает журнал.

Скрипт проверяет:

- запуск;
- переключение каналов: одиночное, быстрое, с придержанной кнопкой;
- набор номера;
- меню, вкладки, избранное и «Недавние»;
- телепрограмму;
- настройки;
- запуск каналов 1–20;
- звук и качество за 2 минуты просмотра.

ВНИМАНИЕ! Во время самопроверки не пользуйтесь стиком. Скрипт нажимает
кнопки в окне на экране. Если на экране не приложение, скрипт
прекращает работу.

1. Соберите отладочную сборку:

   ```bash
   ANDROID_HOME=~/Android/Sdk ./gradlew assembleDebug
   ```

2. Установите её на стик:

   ```bash
   adb -s $TV_STICK install -r app/build/outputs/apk/debug/app-debug.apk
   ```

3. Запустите самопроверку:

   ```bash
   python3 -I tools/selftest.py
   ```

   Ключ `--quick` пропускает каналы 1–20. Ключ `--soak 300` задаёт время
   прослушивания в секундах.

4. Установите обратно релизную сборку.
