# ТВ Каналы

Простое приложение для Android TV: при запуске сразу включает последний
просмотренный канал (или Первый — в настройках), по кнопке OK открывает
сетку каналов в стиле Триколора.

## Пульт

| Кнопка | Действие |
|---|---|
| OK | меню каналов (вкладки сверху, сетка 3 колонки) |
| OK удерживать (в меню) | добавить / убрать из «★ Избранного» |
| Вправо / Влево | следующий / предыдущий канал |
| Вверх | телепрограмма канала (◀ ▶ — другой канал, OK — смотреть) |
| Вниз | список недавних каналов (фокус на предыдущем) |
| Цифры | переход на канал по номеру |
| Назад | в меню — закрыть меню; при просмотре — дважды для выхода |

Каналы 1–20 — федеральная двадцатка с привычными номерами.

Вкладки меню: «Недавние», «★ Избранное», «Все каналы», категории,
«⚙ Настройки». Настройки: что включать при запуске, ограничение качества
(авто / 1080p / 720p / 480p), пропуск нерабочих каналов при листании,
скрытие региональных каналов, время показа плашки, таймер сна, очистка
«Недавних» и «Избранного».

Если у канала несколько ссылок, при ошибке приложение само переходит
на запасную.

Телепрограмма берётся по запросу и держится в памяти 6 часов, на диск ничего
не качается. Источники: сначала tv.mail.ru — сегодняшние телесутки (расписание
вшито в страницу канала как schema.org JSON-LD), сайт российский и со стика
доступен; если канала там нет — epg.iptvx.one/id/<id> (неделя, но сайт за
Cloudflare и у части провайдеров не грузится). Плашка канала показывает
«Сейчас / Далее», в сетке под названием — что идёт, кнопка «вверх» открывает
программу — что шло, идёт и будет. Идентификаторы (x-mailru, x-epg)
проставляет `tools/epg_ids.py` (после prepare.py):

```bash
python3 -I tools/epg_ids.py sources/iptvru.m3u
```

## Сборка и установка

```bash
ANDROID_HOME=~/Android/Sdk ./gradlew assembleRelease
adb -s 192.168.1.107:5555 install -r app/build/outputs/apk/release/app-release.apk
```

## Список каналов с GitHub

Приложение при каждом запуске в фоне скачивает свежий `channels.m3u` (и логотипы
новых каналов) из этого репозитория — с raw.githubusercontent.com, при неудаче
через jsDelivr — и применяет его со следующего запуска. Встроенный в APK список
остаётся запасным. Откуда взят текущий список, видно внизу экрана настроек.

Список пересобирает GitHub Actions каждые 6 часов
(`.github/workflows/update-channels.yml`, можно запустить вручную на вкладке
Actions). Сервер GitHub за границей, поэтому `prepare.py --ci` не выкидывает
потоки, которые недавно работали из России (кэш замеров
`sources/probe_cache.json`), и потоки, которые достаются на стике
(`okru:`, `vitrina:`, `vkplay:`, RuTube). Кэш обновляется запуском
`prepare.py` с ПК в России — время от времени стоит запускать его вручную.

## Самопроверка

Отладочная сборка пишет подробные логи (тег `ST`), а `tools/selftest.py`
гоняет по ним сценарии на стике: запуск, листание (одиночное, быстрое,
придержанная кнопка), цифры, меню, вкладки, избранное, «Недавние»,
телепрограмма, настройки, все федеральные каналы и прослушивание звука:

```bash
ANDROID_HOME=~/Android/Sdk ./gradlew assembleDebug
adb -s 192.168.1.107:5555 install -r app/build/outputs/apk/debug/app-debug.apk
python3 -I tools/selftest.py            # --quick без перебора каналов, --soak 300
```

После проверки поставить обратно релизную сборку.

## Обновление каналов

Источники в `sources/` — в порядке приоритета потоков:

1. `iptvru.m3u` — сохранённая копия плейлиста smolnp/IPTVru (оригинал удалён с GitHub).
2. `rutube.m3u` — официальные прямые эфиры каналов на RuTube (автор трансляции
   совпадает с названием канала): `python3 -I tools/rutube.py sources/iptvru.m3u sources/smotret.m3u > sources/rutube.m3u`
3. `extra.m3u` — вручную проверенные потоки (CDN Wink) для каналов, у которых
   основной поток не играет на стике.
4. `smotret.m3u` — каналы с smotret.tv: прямые потоки, встроенные RuTube и
   OK.ru, официальный плеер «Витрины ТВ»: `python3 -I tools/smotret.py > sources/smotret.m3u`

Ссылки `okru:<id>` и `vitrina:<адрес плеера>` приложение превращает в поток
само перед воспроизведением: токены у этих источников живут от суток до недели.

`tools/prepare.py` проверяет все потоки, выкидывает мёртвые, склеивает
одинаковые каналы из разных источников (лишние ссылки становятся
запасными), ставит федеральные каналы первыми, приводит категории
к единому списку, скачивает логотипы и пишет
`app/src/main/assets/channels.m3u` и `app/src/main/assets/logos/`:

```bash
python3 -I tools/prepare.py sources/iptvru.m3u sources/rutube.m3u sources/extra.m3u sources/smotret.m3u
```

Порядок файлов — приоритет потоков. Исключение — чересстрочные потоки
(эфирный SD, проверяется через ffprobe): на стике их не тянут ни аппаратный,
ни программный декодер, поэтому они уходят в конец списка ссылок канала.
Мастер-плейлисты, где в CODECS не указан звук, заменяются ссылкой на сам
вариант — иначе ExoPlayer теряет звук и не показывает видео.

В приложении: если поток не запустился за 25 секунд или видео пришло, а кадров
нет 12 секунд — переход к следующей ссылке канала.

После этого пересобрать и поставить APK.

Без пересборки: готовый `channels.m3u` (в формате, который пишет prepare.py)
можно положить в папку приложения — он перекроет встроенный:

```bash
adb -s 192.168.1.107:5555 push channels.m3u /sdcard/Android/data/ru.home.tvchannels/files/channels.m3u
```
